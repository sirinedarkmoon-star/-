# وين راحو دراهمي؟

نسخة مطوّرة أولية لتطبيق متابعة المصروفات والرصيد الشهري واحتياط الطوارئ.

## الملفات
- `index.html`: واجهة التطبيق ووظائفه، مع العربية والإنجليزية والفرنسية وجولة ترحيبية.
- `manifest.json`: بيانات التثبيت كتطبيق ويب تقدمي.
- `sw.js`: التخزين المؤقت للعمل دون إنترنت بعد أول تحميل.
- `icon.svg`: أيقونة التطبيق.

## التشغيل
للتجربة السريعة افتحي `index.html` في متصفح حديث. التثبيت والعمل دون إنترنت يحتاجان إلى نشر الملفات عبر HTTPS مثل GitHub Pages.

## البيانات
تُحفظ العمليات والإعدادات محليًا على الجهاز. لا يوجد تصدير أو استرجاع للنسخ الاحتياطية في هذه النسخة؛ قد تُفقد البيانات عند مسح بيانات المتصفح أو تغيير الجهاز.

## ملاحظات
- لا يوجد تسجيل دخول أو ربط بنكي.
- تغيير العملة يغيّر رمز العرض فقط ولا يحوّل القيم.
- الرصيد المتبقي يُرحّل تلقائيًا، واحتياط الطوارئ مستقل.
- تتضمن صفحة الاحتياط خانة لحفظ قواعد الاستخدام الشخصية.
- اختبري جميع العمليات على الهاتف قبل الاعتماد على التطبيق أو بيعه.
